# 0.1.0 — initial release

Publication status: published to npm on 2026-09-18 as
`@maroonedog/waypoint@0.1.0`, with `latest` pointing to `0.1.0`.
Registry integrity matches the verified tarball below.

## Included

- Typed form paths, React and Vue bindings, and framework-independent runtime.
- Standard Schema, Zod, Valibot, and Luq resolvers. Luq requires 2.9.0 or later
  within major version 2.
- Opt-in partial validation for Zod, Valibot, and Luq. Submission validates the
  whole form; unsupported selections fall back to whole-form validation.
- Async validation cancellation, array operations, and server-error adoption.

## Adoption constraints

- ESM, Node 20+, with TypeScript 5.9+ as the tested compiler baseline.
- Applications own the compilation-wide `WaypointForms` augmentation. This is
  a type registry, not shared runtime form state. Reusable libraries should
  export adapters without registering them automatically.
- `skipLibCheck` can hide conflicting registrations in dependency declarations.
  Scoped registries, multiple installed versions, and declaration bundlers are
  not established compatibility guarantees for this release.
- Luq cross-field dependencies must be declared for partial validation. See
  [partial validation](../partial-validation.md) for execution scopes and fallback.
- Production adoption and manual screen-reader acceptance are not established.
  APIs may change during 0.x.
- The source repository is private. Installation and the packaged README do not
  require repository access; repository links may require authorization.
